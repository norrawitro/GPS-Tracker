เปิดหน้าต่างถาม "คุณอยู่ที่ไหน?"

ให้แอปเด้งหน้าต่างถามชื่อสถานที่ขึ้นกลางจอได้ แม้กำลังใช้แอปอื่นอยู่ ไม่อย่างนั้นจะมีแค่การแจ้งเตือนเล็ก ๆ ด้านบน

ต้องเปิดสิทธิ์ตำแหน่งก่อน

แอปยังไม่ได้รับสิทธิ์เข้าถึงตำแหน่ง จึงเริ่มบันทึกไม่ได้ เปิดหน้าตั้งค่าแอป แล้วไปที่ "สิทธิ์" → "ตำแหน่ง" → เลือก "อนุญาตเฉพาะขณะใช้แอป" และเปิด "ใช้ตำแหน่งที่แม่นยำ"

ถ้าลืมรหัสผ่าน ต้องล้างข้อมูลแอปในตั้งค่าเครื่อง ซึ่งจะลบสถานที่ที่จำไว้ทั้งหมด (ไฟล์ CSV ในโฟลเดอร์ Documents ยังอยู่)

ส่งสถานะขึ้น GitHub

แอปส่งสถานะเฉพาะเมื่อมีไฟล์คำสั่งในโฟลเดอร์ commands/ ของ repo หรือเมื่อกด "ส่งสถานะตอนนี้" ไม่มีการส่งเองตามเวลา ไฟล์ที่ส่งขึ้นไปถูกเข้ารหัส AES-256 ทุกไฟล์

บันทึกการทำงาน

    สำรองข้อมูลในแอป

    สถานที่ที่บันทึกไว้ การเตือน และค่าตั้ง เก็บเป็นไฟล์ใน Documents/GPS-Track/backup/ ไฟล์เส้นทาง CSV ไม่ต้องสำรอง เพราะอยู่ในโฟลเดอร์ Documents อยู่แล้ว

    ย้อนกลับไปเวอร์ชันเก่า

    Android ไม่ยอมติดตั้งเวอร์ชันเก่าทับเวอร์ชันใหม่ ต้องถอนแอปก่อน ซึ่งจะลบสถานที่ การเตือน และค่าตั้งในแอป แอปจะสำรองข้อมูลให้ก่อนเสมอ ไฟล์เส้นทาง CSV ไม่หาย

    -

    1. สำรองข้อมูลไว้ที่
    2. ดาวน์โหลดเวอร์ชันเก่าไว้ที่
    3. กด "ถอนแอปนี้" ด้านล่าง
    4. เปิดแอปจัดการไฟล์ ไปที่โฟลเดอร์ Download แล้วแตะไฟล์ด้านบนเพื่อติดตั้ง
    5. เวอร์ชันเก่าบางรุ่นไม่มีปุ่มกู้ข้อมูล ถ้าอัปเดตกลับมาเวอร์ชันนี้ภายหลัง ใช้ "กู้ข้อมูลจากไฟล์สำรอง" เพื่อเอาสถานที่และการเตือนกลับมา

    อัปเดตแอป

    เวอร์ชันที่ติดตั้ง -

    ดาวน์โหลดเวอร์ชันใหม่จาก GitHub แล้วติดตั้งทับ ไฟล์บันทึกและสถานที่ที่จำไว้ยังอยู่ครบ ถ้ากำลังบันทึก ให้กดเริ่มบันทึกใหม่หลังอัปเดต

    ย้อนไปเวอร์ชัน ?

    แอปจะสำรองข้อมูล หยุดการบันทึก และดาวน์โหลดเวอร์ชันนี้ไว้ในโฟลเดอร์ Download จากนั้นต้องถอนแอปนี้แล้วติดตั้งไฟล์ที่ดาวน์โหลดเอง

    หลังถอนแอป สถานที่ การเตือน และค่าตั้งในแอปจะหายจากเครื่อง (มีไฟล์สำรองไว้ให้) ไฟล์เส้นทาง CSV ไม่หาย

    บันทึกชื่อสถานที่

    แอปจะจับพิกัดตอนนี้ แล้วบันทึกชื่อนี้ไว้สำหรับจำสถานที่ครั้งต่อไป

    คุณอยู่ที่ไหน?

    ยังไม่มีสถานที่ที่บันทึกไว้ใกล้จุดนี้

    ปิดหน้าต่างนี้โดยไม่พิมพ์ชื่อ จะบันทึกแค่วันเวลาและพิกัด

    ใส่รหัสผ่านเพื่อเข้าแอป

    การบันทึกการเดินทางยังทำงานอยู่เบื้องหลังระหว่างที่แอปล็อก
