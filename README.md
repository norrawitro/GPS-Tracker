# GPS-Tracker

แอป Android บันทึกการเดินทางด้วย GPS จับพิกัดตามช่วงเวลาที่ตั้งไว้ทำงานเบื้องหลังได้ และจำชื่อสถานที่ที่เคยไป

## ปุ่มหลัก

| ปุ่ม | ทำอะไร |
|---|---|
| 1 เริ่ม/หยุดบันทึก | เริ่มหรือหยุดการจับพิกัดเบื้องหลัง ถ้ายังไม่ได้เปิดสิทธิ์ตำแหน่ง จะเริ่มไม่ได้และขึ้นคำเตือน |
| 2 บันทึกชื่อสถานที่ | ตั้งชื่อจุดที่อยู่ตอนนี้ (เฉพาะตอนกำลังบันทึก) บันทึกลงฐานข้อมูลสถานที่และไฟล์ของวันนั้น |
| 3 ไฟล์บันทึก | ดูไฟล์เส้นทางแยกตามปี เดือน วัน แตะเพื่อเปิดดู หรือแชร์ไปแอปอื่น |
| 4 ตั้งค่า | ความถี่ (1 นาที ถึง 12 ชั่วโมง) จำนวนครั้งก่อนตรวจชื่อสถานที่ รัศมีจับคู่ (เมตร) และปุ่มตรวจหาอัปเดตแอป |

## การทำงาน

1. ทุกครั้งที่จับพิกัด จะเขียน 1 แถวลงไฟล์ของวันนั้น และนับเพิ่ม 1
2. เมื่อนับครบตามที่ตั้งไว้ จะเทียบพิกัดกับทุกสถานที่ที่เคยตั้งชื่อ
   - ถ้าอยู่ในรัศมีของสถานที่ใด จะใส่ชื่อนั้นให้เองโดยไม่ถาม
   - ถ้าไม่ตรงกับที่ไหนเลย จะถามว่า "คุณอยู่ที่ไหน?" ถ้าแอปเปิดอยู่จะเป็นหน้าต่างในแอป ถ้าแอปอยู่เบื้องหลังจะเด้งหน้าต่างลอยกลางจอทับแอปอื่น (ต้องอนุญาต "แสดงทับแอปอื่น" ครั้งแรก) พร้อมการแจ้งเตือนที่พิมพ์ตอบได้
   - ถ้าปิดหรือปัดทิ้งโดยไม่ตั้งชื่อ จะบันทึกแค่วันเวลาและพิกัด
3. ตัวนับกลับเป็น 0 เมื่อเริ่มบันทึกใหม่ หรือเมื่อตรวจชื่อสถานที่เสร็จ

## รหัสผ่านเข้าแอป

ตั้งได้ในปุ่ม 4 (ตั้งค่า) ไม่บังคับ เมื่อตั้งแล้ว แอปจะล็อกทุกครั้งที่ออกจากแอป ระหว่างล็อกการบันทึกยังทำงานต่อ ใส่ผิด 5 ครั้งต้องรอ 30 วินาที เก็บไว้แค่ค่า hash แบบ PBKDF2 ไม่เก็บรหัสผ่านจริง ถ้าลืมรหัสผ่าน ต้องล้างข้อมูลแอป

## ไฟล์ที่บันทึก

- **เส้นทางประจำวัน (CSV):** `Documents/GPS-Track/YYYY/MM/DD/YYYY-MM-DD-track.csv`
  - คอลัมน์: `วันเวลา,ละติจูด,ลองจิจูด,ชื่อสถานที่,ใกล้สถานที่,ระยะห่าง(เมตร)`
  - ตัวอย่าง: `04-11-2026 08:30:00,13.756500,100.501800,สำนักงาน,สำนักงาน,0`
  - `ชื่อสถานที่` มีค่าเฉพาะตอนตรวจชื่อสถานที่หรือตั้งชื่อเอง ส่วน `ใกล้สถานที่` และ `ระยะห่าง(เมตร)` บันทึกทุกครั้ง เป็นสถานที่ที่ตั้งชื่อไว้ซึ่งอยู่ใกล้ที่สุด (ว่างถ้ายังไม่เคยตั้งชื่อสถานที่ใดเลย)
  - โฟลเดอร์ตั้งตามวันที่ของเครื่องตอนบันทึกแต่ละแถว ถ้าเปลี่ยนวันที่ในเครื่อง จะขึ้นโฟลเดอร์ใหม่
- **ฐานข้อมูลสถานที่ (SQLite):** ตาราง `places` (ชื่อสถานที่, ละติจูด, ลองจิจูด, รัศมีจับคู่เป็นเมตร, วันที่บันทึกครั้งแรก) เก็บในพื้นที่ของแอป ไม่แสดงให้แก้ไขในหน้าดูไฟล์

## ข้อจำกัด

- ปิดหน้าจอหรือกด Home ได้ การบันทึกยังทำงานต่อ และมีการแจ้งเตือน "กำลังบันทึกการเดินทาง" ค้างไว้
- **Force stop** (ตั้งค่า → แอป → บังคับหยุด) จะหยุดการบันทึกทันที เปิดแอปใหม่จะเห็นสถานะ "หยุดบันทึก"
- เปิดเครื่องใหม่แล้วต้องกดเริ่มบันทึกอีกครั้ง
- บางยี่ห้อ เช่น TECNO ปิดแอปเบื้องหลังบ่อย ให้ตั้งแบตเตอรี่ของแอปเป็น "ไม่จำกัด"
- ถ้าถอนการติดตั้งแล้วติดตั้งใหม่ แอปจะมองไม่เห็นไฟล์ CSV เก่าในหน้าดูไฟล์ (ไฟล์ยังอยู่ในโฟลเดอร์ Documents)

## Build และ Release

- GitHub Actions build APK ทุก PR และทุก push เข้า `main` จะสร้าง Release `v1.0.<เลขรอบ>`
- ต้องมี secrets `SIGNING_KEYSTORE_BASE64` และ `SIGNING_STORE_PASSWORD` (ใช้กุญแจชุดเดียวกับ N-assistant ได้)
- ถ้ามือถือวางข้อความได้ไม่เกิน 2,000 ตัวอักษร ให้แบ่งกุญแจเป็น 2 ส่วน ใส่ส่วนแรกใน `SIGNING_KEYSTORE_BASE64` และส่วนที่เหลือใน `SIGNING_KEYSTORE_BASE64_2` แล้ว build จะต่อให้เอง
